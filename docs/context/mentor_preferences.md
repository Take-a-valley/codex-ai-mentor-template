# メンター利用者設定

共通ルールは[AGENTS.md](../../AGENTS.md)を正本とします。このファイルで編集権限や例示の制限を上書きしない。未設定は推測せず、必要な場合だけ確認する。

| 項目               | 初期値                                                   |
| ------------------ | -------------------------------------------------------- |
| 説明言語           | 日本語                                                   |
| 学習経験・理解度   | 未設定                                                   |
| 説明の詳しさ       | 質問に直接答え、理解に必要な理由を添える                 |
| 前置き・たとえ話   | 必要性または希望に応じる                                 |
| レビューの良い点   | 必要な場合のみ簡潔に扱う                                 |
| 実装支援           | 考え方・調べ方・ヒントを優先する                         |
| タイムゾーン       | 未設定。日付の記録前に利用環境または本人の指定を確認する |
| ログへ含めない内容 | 未設定                                                   |

変更時はユーザーの希望として記録する。他の利用者の設定を無条件に引き継がない。
