# docs/architecture

このディレクトリには、ユーザーが作成する設計書・仕様書を配置します。

## 重要ルール

- このディレクトリ配下のMarkdownは、ユーザー作成の学習成果物として扱います。
- AIは通常、レビュー、助言、構成・粒度の説明、改善提案を行います。
- このディレクトリのファイルをAIに編集させる場合は、ユーザーが対象と変更範囲を明示して依頼してください。依頼された範囲を超えて編集しません。
- 共通の編集権限は[AGENTS.md](../../AGENTS.md)を正本とします。レビューや助言の依頼だけでは編集許可になりません。

## 想定する設計書

- `requirements.md`：要件定義書
- `basic_design.md`：基本設計書
- `detail_design.md`：詳細設計書
- `db_design.md`：DB設計書
- `api_design.md`：API設計書
- `screen_design.md`：画面設計書
- `test_design.md`：テスト設計書

名称・分割方法はプロジェクトに合わせて決めます。すべてを必須とせず、必要性と範囲を確認します。
設計と実装を照合し、実装済み・検証済みの記録と、予定仕様を区別します。
